# data-science-and-big-data-technology

数据科学与大数据技术课程项目仓库，涵盖机器学习、自然语言处理、概率图模型、统计推断、优化算法、采样技术等核心领域的算法实现与实践。

## 🧩 模块详解

### 1. C++ - 哈夫曼编码
基于C++实现的哈夫曼编码算法，用于数据无损压缩，涵盖构建哈夫曼树、生成编码表、编码与解码完整流程。

### 2. Machine_Learning - SVM (SMO)
使用序列最小优化（SMO）算法实现支持向量机训练，包含线性核与非线性核支持，是经典机器学习算法的手工实现。

### 3. NLP - TF-IDF 文本相似度
结合 jieba 分词与 Gensim 库，实现基于 TF-IDF 向量空间模型的中文文本相似度计算，可用于文本检索、文档聚类等场景。

### 4. Optimisation - 蒙特卡洛 ATE 估计
通过蒙特卡洛模拟方法进行因果推断中的平均处理效应（ATE）估计，用于观察性研究中的因果效应评估。

### 5. Probability_Diagram_Model - HMM 词性标注
基于隐马尔可夫模型（HMM）实现中文词性标注，涵盖前向算法、维特比解码等核心概率图模型算法。

### 6. Sampling_Technique - 分层随机抽样
使用 R 语言实现分层随机抽样分析，对比不同抽样策略的估计精度，是抽样调查技术的实践案例。

### 7. Statistics - BMI 与高血压统计推断
针对 BMI 指数与高血压关联性的统计推断脚本，包含假设检验、置信区间、相关性分析等经典统计方法。

## 🛠 技术栈

- **编程语言**: Python, C++, R
- **机器学习**: 支持向量机 (SVM), SMO 算法
- **自然语言处理**: jieba, Gensim, TF-IDF
- **概率图模型**: 隐马尔可夫模型 (HMM), 维特比算法
- **统计方法**: 假设检验、置信区间、分层抽样、蒙特卡洛模拟
- **因果推断**: 平均处理效应 (ATE) 估计

## 🚀 使用方法

克隆仓库后进入对应目录，根据各模块说明运行相应脚本：

```bash
git clone https://github.com/Silas119/data-science-and-big-data-technology.git
cd data-science-and-big-data-technology
```

各模块独立运行，具体依赖请参考各目录下的代码文件头部注释。
