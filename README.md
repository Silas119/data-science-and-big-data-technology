# data-science-and-big-data-technology

数据科学与大数据技术课程项目仓库，涵盖机器学习、自然语言处理、概率图模型、统计推断、优化算法、抽样技术等核心领域的算法实现与实践。

## 🧩 模块详解

### 1. C++ 
这个板块包含了基础的C++程序和面向对象的部分代码，还有部分的进阶，例如启发算法和信息编码的内容。

### 2. Machine_Learning 
这部分基于李航机器学习和机器学习实战的代码复现与算法实现，包括监督学习、无监督学习以及一小部分深度学习的内容。

### 3. NLP 
该部分对文本挖掘和自然语言处理的基本操作（分词、特征提取、主题分析等）进行了实现。

### 4. Optimisation 
该部分基于优化理论求解问题，包含约束问题、无约束等多种问题的优化实现方法。

### 5. Probability_Diagram_Model 
该部分是概率图模型理论的实践，从基础理论（概率论、图论、信息论）
到模型理论（贝叶斯分类器、HMM、条件随机场、贝叶斯网络、决策树）
### 6. Sampling_Technique 
该部分基于R实现了抽样方法的应用，实现不同抽样方法和统计计算。

### 7. Statistics
该部分通过BMI与心脏收缩压舒张压的例子，对实际问题进行参数估计和统计推断，并借助Python实现。

### 8. Data_Structure
基于数据结构实现一些简单算法。

## 🛠 技术栈

- **编程语言**: Python, C++, R
- **机器学习**: 监督学习、无监督学习、深度学习、强化学习
- **自然语言处理**: jieba, Gensim, TF-IDF
- **概率图模型**: HMM、MRf、BN
- **统计方法**: 假设检验、置信区间、分层抽样
- **数据结构**:队列、链表、栈、树、图

## 🚀 使用方法

克隆仓库后进入对应目录，根据各模块说明运行相应脚本：

```bash
git clone https://github.com/Silas119/data-science-and-big-data-technology.git
cd data-science-and-big-data-technology
```

各模块独立运行，具体依赖请参考各目录下的代码文件头部注释。
